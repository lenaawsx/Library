Тема: Личная библиотека — учет книг, статусов чтения и пользовательских заметок.

---

## Описание и основной сценарий
Приложение предназначено для ведения личной коллекции книг. Позволяет структурировать прочитанную литературу, списки к прочтению, оценки и личные впечатления.

**Основной сценарий использования:**
Пользователь открывает каталог, фильтрует книги по статусу чтения (прочитано / в процессе / в планах) и оценкам (1–5 звезд), добавляет новые произведения, редактирует заметки и управляет справочниками авторов и жанров.
